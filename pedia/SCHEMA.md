# PyCoaPedia database schema

`pyCoastal/pedia/pycoapedia.sqlite` is a single SQLite file (read it with
`pyCoastal.pedia`, `python -m pyCoastal.pedia sql "..."`, or any SQLite
client). It is regenerated by `pedia/build_pedia.py` from the source research
database; never edit it by hand.

## Tables

| Table | One row per | Key columns |
|-------|-------------|-------------|
| `metadata` | build fact | `key`, `value` (name, generated, counts) |
| `topics` | topic in the tree | `id` (dotted path, e.g. `structures.overtopping`), `parent_id` (NULL at the top), `label`, `description`, `level`, `n_papers`, `n_claims`, `n_equations` |
| `synthesis` | curated statement | `topic_id`, `section`, `statement` |
| `claims` | atomic finding | `id`, `topic_id`, `paper_id`, `text`, `regime`, `evidence_type`, `evidence_summary`, `confidence`, `source_locator` |
| `claim_relationships` | link between two claims | `source_claim_id`, `target_claim_id`, `relationship`, `rationale` |
| `equations` | named relation | `id`, `topic_id`, `paper_id`, `name`, `latex`, `equation_type`, `variables` (JSON), `regime` |
| `papers` | paper | `id`, `doi`, `title`, `authors`, `first_author`, `year`, `journal`, `abstract`, `citation_count`, `access`, `open_url`, `open_version`, `open_license` |
| `paper_topics` | paper classified under a topic | `paper_id`, `topic_id`, `role` (`specific`, `related`, ...), `confidence` |
| `paper_extractions` | paper, structured summary | `paper_id`, `research_question`, `principal_results`, `quantitative_findings`, `parameter_ranges`, `engineering_implications`, `limitations`, `applicability_conditions`, `contradictions`, ..., `extraction_source` |
| `parameters` | parameter reported by a paper | `paper_id`, `name`, `symbol`, `units`, `minimum_value`, `maximum_value`, `role` |
| `models`, `paper_models` | numerical model and its use | `name`, `model_family`; `paper_id`, `model_id`, `usage_role` |
| `datasets`, `paper_datasets` | dataset and its use | `name`, `persistent_id`, `url` |
| `field_sites`, `paper_field_sites` | field site | `name`, `country`, `latitude`, `longitude` |
| `module_topics` | pyCoastal design module to topic | `module` (e.g. `seawall`), `module_label`, `topic_id`, `position` |
| `search` | searchable item (FTS5) | `kind`, `ref`, `topic_id`, `title`, `body` |

### Controlled values

- `synthesis.section`: `well_established`, `governing_physics`,
  `dimensionless_parameters`, `major_equations`, `typical_methods`,
  `numerical_models`, `experimental_datasets`, `validated_ranges`,
  `recent_advances`, `disagreements`, `limitations`, `open_questions`,
  `seminal_papers`.
- `claims.confidence`: `direct_finding`, `literature_review_statement`,
  `inferred_relationship`, `proposed_hypothesis`.
- `claims.evidence_type`: `field`, `experimental`, `numerical`, `analytical`,
  `mixed`, `review`, `author_hypothesis`.
- `claim_relationships.relationship`: `supports`, `contradicts`, `extends`,
  `validates`, `compares_against`, `applies_to`, `derived_from`,
  `uses_method_from`, `same_physical_process`, `same_dataset`,
  `same_experiment`, `same_model`.
- `papers.access`: `open`, `restricted`, `unavailable`, `unknown`.
  `open_url` is set only for `open` papers: the best verified lawful copy,
  published version first. `open_version`: `version_of_record`,
  `accepted_manuscript`, `submitted_manuscript`, `preprint`.
  `open_license`: `CC BY` (with `-NC`, `-ND`, `-SA`), `public domain`, or
  `read only` when the copy is free to read but carries no open license.
- `paper_extractions.extraction_source`: `full_text` or `abstract`.
- `search.kind`: `topic`, `synthesis`, `claim`, `equation`, `paper`. `ref` is
  the row id in that table, or the topic id for `topic` and `synthesis`.

## Example queries

Full-text search, best matches first (Porter stemming, so `overtop*` or
`overtopping` both work):

```sql
SELECT kind, ref, topic_id, title,
       snippet(search, 4, '[', ']', '...', 20) AS snippet
FROM search WHERE search MATCH 'overtopping AND foreshore'
ORDER BY rank LIMIT 10;
```

Everything under a branch of the tree:

```sql
SELECT id, label, n_claims FROM topics
WHERE id = 'scour' OR id LIKE 'scour.%' ORDER BY id;
```

Experimental claims on a topic, with their citations:

```sql
SELECT c.id, c.text, c.regime, p.first_author, p.year, p.doi
FROM claims c JOIN papers p ON p.id = c.paper_id
WHERE c.topic_id = 'structures.overtopping' AND c.evidence_type = 'experimental';
```

Open copies of the papers behind a topic, published versions under an
open license first:

```sql
SELECT p.first_author, p.year, p.open_version, p.open_license, p.open_url
FROM paper_topics pt JOIN papers p ON p.id = pt.paper_id
WHERE pt.topic_id = 'structures.seawalls' AND p.open_url IS NOT NULL
ORDER BY p.open_license = 'read only', p.open_version <> 'version_of_record';
```

Where the literature disagrees:

```sql
SELECT a.text AS claim, b.text AS contradicted_by, r.rationale
FROM claim_relationships r
JOIN claims a ON a.id = r.source_claim_id
JOIN claims b ON b.id = r.target_claim_id
WHERE r.relationship = 'contradicts';
```

The validated ranges behind a pyCoastal design module:

```sql
SELECT m.topic_id, s.statement
FROM module_topics m JOIN synthesis s ON s.topic_id = m.topic_id
WHERE m.module = 'seawall' AND s.section = 'validated_ranges'
ORDER BY m.position;
```

Quantitative findings of the papers on a topic:

```sql
SELECT p.first_author, p.year, e.quantitative_findings
FROM paper_topics pt
JOIN papers p ON p.id = pt.paper_id
JOIN paper_extractions e ON e.paper_id = p.id
WHERE pt.topic_id = 'scour.structures' AND e.quantitative_findings IS NOT NULL;
```
